# Taller Flask – Diseño Web (Unidad 3)

Aplicación Flask con un menú principal y dos formularios:

- **Ejercicio 1:** 3 notas (10–70) + asistencia (0–100). Muestra el promedio y APROBADO/REPROBADO
  (promedio >= 40 **y** asistencia >= 75).
- **Ejercicio 2:** 3 nombres. Muestra el nombre con más letras y su cantidad de caracteres.

## Estructura

```
taller_flask/
├── run.py              # aplicación Flask (rutas y funciones)
├── requirements.txt
├── templates/
│   ├── base.html       # plantilla base (carga el CSS)
│   ├── index.html      # menú principal
│   ├── ejercicio1.html
│   ├── ejercicio2.html
│   └── error.html
└── static/
    ├── css/estilos.css
    └── img/
```

Abrir http://127.0.0.1:5000
